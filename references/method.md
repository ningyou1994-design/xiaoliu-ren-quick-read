# 起课方法与数据口径

## 方法性质

本技能是为 AI Skill 设计的现代轻量规则：借用小六壬六宫名称和通行象义，以“字宫—时宫—落宫”形成可重复计算的娱乐性速断。它不是经科学验证的预测模型。不要把它表述为古籍定本、门派秘传或历史上唯一的算法。

“可重复计算”只表示相同输入会得到相同宫位标签，不表示这些标签能够揭示未来、判断他人或证明解读准确。

## 六宫编号

固定顺序如下，逢六循环：

1. 大安
2. 留连
3. 速喜
4. 赤口
5. 小吉
6. 空亡

任意正整数 `n` 对应的宫位编号为：

```text
((n - 1) mod 6) + 1
```

## 起课时间口径

时间必须是用户提出问题并准备起课时的真实当地时刻，不是凭感觉另选的时间，也不是为了得到不同结果而挑选的“吉时”。用户可如实填写时辰或 24 小时制时间；只说“现在”时，仅在能够可靠确认其当地时间与时区的情况下代为换算。

本 Skill 无法验证用户填写是否真实，因此只需清楚提示，不索取定位或其他个人信息。用户明确给出未来时间、随选时间或重起时改过的时间时，不计算，请其改填实际起课时间。补录已经发生的起课时，只采用当时真实记录，并在输出中标明“补录”。

## 笔画口径

默认从随包数据 `assets/unihan-total-strokes.txt` 读取所选字符的 `kTotalStrokes`。数据源为 Unicode 17.0.0 的 Unihan 数据库；这一字段提供 Unicode 代表字形的通行总笔画数，是为了让计算稳定可复核，不代表某一书法、字典或术数门派的唯一笔画标准。

数据来源：

- Unicode Unihan：<https://www.unicode.org/reports/tr38/>
- 原始数据包：<https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip>
- 数据文件：`Unihan_IRGSources.txt` 中的 `kTotalStrokes`

简体、繁体和异体字按用户实际输入的 Unicode 字符分别查询。用户坚持另一种笔画标准时，接受其明确提供的正整数，用 `--strokes` 覆盖默认值，并在课面标明“用户指定笔画”。不要悄悄改数。

## 三宫公式

设所选字的总笔画为 `S`，时辰编号为 `H`：

```text
字宫编号 = ((S - 1) mod 6) + 1
时宫编号 = ((H - 1) mod 6) + 1
落宫编号 = ((S + H - 2) mod 6) + 1
```

落宫等于从字宫起，将当前字宫算作第一步，再按时辰编号顺数所得的宫位。

### 复算示例

输入“安”，按默认数据为 6 画；亥时编号为 12：

```text
字宫 = ((6 - 1) mod 6) + 1 = 6 = 空亡
时宫 = ((12 - 1) mod 6) + 1 = 6 = 空亡
落宫 = ((6 + 12 - 2) mod 6) + 1 = 5 = 小吉
```

因此课面为：字「安」·6画｜亥时｜字宫空亡｜时宫空亡｜落宫小吉。这个结果用于娱乐性象征解读，不构成对现实事件的确定判断。

## 异常处理

- 脚本找不到字符时：确认是否真的只有一个汉字；仍找不到则请用户提供采用的笔画数。
- 用户只给“现在”：仅在能够确认当地时间和时区时换算，并把实际起课时间写进课面。
- 用户给未来时间或承认时间是随便选的：不计算，请其改填此刻的实际起课时间。
- 用户为同一问题改时间重起：沿用第一次课面，不通过换时间刷新结果。
- 用户在时辰交界：按其给出的分钟严格换算；只说“大约”时，请其确认前后哪一时辰。
- 用户给出两个以上字符：不相加、不取平均，请其保留一个。
- 复算出现差异：先核对原字是否简繁有别、时辰是否跨界、是否使用了手动笔画覆盖。
